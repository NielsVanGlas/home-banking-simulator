# Home Banking Simulator

> Applicativo full-stack per la gestione simulata di conti correnti bancari. 
È il mio project work per la prova finale del corso di laurea L-31 Informatica per le Aziende Digitali fornito dall'università Pegaso.

**AVVERTENZE:** alo stato attuale il progetto è da intendersi come un puro strumento didattico e tutte le operazioni finanziari sono simulate.
Il progetto ha un meccanismo interno che genera iban realistici, ma non sono in alcun modo veri iban assegnati agli utenti e la generazione di iban realmente in uso nel Mondo reale è da considerarsi una pura coincidenza.

> L'applicazione è avviabile installando docker sulla propria macchina e lanciando il seguente comando nella cartella di root del progetto.

```bash
docker compose up -d --build
```

> Una volta avviata, l'app è accessibile all'indirizzo: http://localhost:3000
